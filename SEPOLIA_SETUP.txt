# QUICK START

## 1. Install

pip install -r requirements.txt

## 2. Configure .env

Copy .env.example -> .env

Fill:
- SEPOLIA_RPC
- PRIVATE_KEY
- WALLET_ADDRESS
- CONTRACT_ADDRESS

## 3. Run

python main.py

## 4. Deploy Contract

Open:
https://remix.ethereum.org

Deploy contracts/FatigueGuardian.sol on Sepolia.
